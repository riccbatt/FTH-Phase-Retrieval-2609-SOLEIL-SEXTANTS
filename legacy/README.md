# Legacy notebooks

These notebooks are retained for reference and are not part of the active
workflow.

- `previous_workflow/` contains the canonical FTH, preprocessing, and
  stitching notebooks before the explicit detector/beamstop PNG refactor.
- `mask_creation_notebooks/` contains the retired Paint and Napari mask
  creation notebooks. Masks are now created manually as red PNG files.
- `imported_notebook_versions/` preserves the working copies imported from the
  other computer, including their original outputs and exploratory cells.

The active notebooks remain in the repository root.
